# 2026/10/02

## 진행한 작업
- 프로젝트를 진행하면서 의문이 들었던 사항에 대한 정리.

### 1. 의문


```cpp

T* Get()

const T* Get() const

```
-  기존에 알던 오버로딩의 조건은 함수 명은 일치하고 인자가 다른 경우 였음
-  하지만 위 코드도 성립 된다는 사실을 알고 자세히 알아보기로 함.

### 2. 설명

- 멤버 함수에는 눈에 안보이는 첫번째 인자 this가 존재해서 위 함수의 시그니처는 대략 이렇게 생김

```cpp
T*       Get(T*       this);   // 일반, 가리키는 객체 수정 가능 포인터
const T* Get(const T* this);   // const, 가리키는 객체 수정 불가 포인터(pointer to const)
```
- T*와 const T*가 서로다른 변수 타입이므로 함수 오버로딩이 성립함


### 3. 결론

- 함수 뒤의 `const`는 숨은 인자 `this`의 타입을 `const T*`로 바꾼다. **인자가 같아도 다른 함수.**
- `T*`와 `const T*`는 다른 타입이고, const를 붙이는 변환만 자동. 떼려면 `const_cast`.
- 참고
    1. Effective C++ 항목 3은 반대 방향(비const가 const를 호출하고 결과에서 const를 뗌)을 권함. 로직이 const 함수 안에 있으면 상태를 바꾸는 코드를 넣는 순간 컴파일러가 막아 주기 때문.
