### 1. 텍스처 공간과 노말 맵

#### Tangent 좌표계
![Tangent 좌표계](/assets/img/sherlock/tangent/tangent-01.png)

- 텍스처 표면에 수직인 방향이 **Normal**.
- 텍스처가 회전 없이 그대로 매핑되었다면 Tangent 좌표계는 다음과 같음.
    1. **Tangent**는 X 방향
    2. **Bi-tangent**는 -Y 방향
    3. **Normal**은 -Z 방향

#### 노말 맵 샘플링 범위
![노말 맵 샘플링](/assets/img/sherlock/tangent/tangent-02.png)

- 셰이더에서 텍스처 좌표로 샘플링하면 값의 범위가 0~1(UNORM 포맷 기준).
- 양수만으로는 360도 방향의 노멀을 표현할 수 없으므로 **-1.0~1.0 범위로 변환**해서 노멀로 사용.
- 샘플링해 온 노멀은 **텍스처 좌표계 기준**으로 정의된 값.

```hlsl
// 모델 좌표계 기준 TBN
float3 T = float3(1, 0, 0);
float3 B = float3(0, -1, 0);
float3 N = float3(0, 0, -1);
```

### 2. 단순한 경우: 직접 만든 TBN

#### 텍스처 공간 → 모델 공간 변환 행렬
- 텍스처 공간의 노멀을 모델 공간으로 보내는 변환 행렬을 만듦.
- T는 Tangent(모델의 X), B는 Bi-tangent(모델의 -Y), N은 Normal(모델의 -Z).

![TBN 행렬 1](/assets/img/sherlock/tangent/tangent-03.png)
![TBN 행렬 2](/assets/img/sherlock/tangent/tangent-04.png)

#### 셰이더 코드

```hlsl
float3 normalTex = /* normalMap의 rgb 샘플링 */;
normalTex = 2.0 * normalTex - 1.0; // [-1.0, 1.0] 범위로 조절

// 모델 좌표계 기준 TBN
float3 T = float3(1, 0, 0);
float3 B = float3(0, -1, 0);
float3 N = float3(0, 0, -1);

// TBN -> Model 좌표계 변환 행렬
float3x3 TBN = float3x3(T, B, N);

// 이걸로 변환해서 노말 맵의 노멀을 모델(월드) 좌표계로 가져옴
normalWorld = normalize(mul(normalTex, TBN));
```

- 위 경우는 TBN 벡터를 손으로 구해서 행렬을 만든 **가장 단순한 예시**.
- 일반적인 모델에서는 통하지 않음.

### 3. 일반적인 모델의 TBN

#### 삼각형 기준으로 TBN 구하기
![삼각형 기준 TBN 1](/assets/img/sherlock/tangent/tangent-05.png)

- 텍스처 매핑은 삼각형에 텍스처의 일부를 샘플링해서 붙이는 것.
- TBN이 **삼각형 입장에서 어느 방향인지** 계산하면 변환 행렬을 만들 수 있음.
- 삼각형의 각 정점은 텍스처 좌표(UV)와 월드 좌표를 둘 다 가지고 있음.
- 그래서 텍스처 좌표계 위에 월드 좌표계의 삼각형을 그릴 수 있고, 이를 이용해 TBN을 삼각형이 원래 있던 월드로 변환 가능.

![삼각형 기준 TBN 2](/assets/img/sherlock/tangent/tangent-06.png)

- 3차원 모델에 텍스처링을 한다는 것은 텍스처를 3차원 표면에 붙인다는 의미.
- 텍스처의 Tangent 좌표계가 모델에 붙을 때 어떤 방향으로 변환되는지 알면 텍스처에 정의된 노멀도 변환 가능.

#### 셰이더 코드

```hlsl
float3 N = normal; // 3D 모델의 노말 벡터를 그대로 사용

// Tangent (그람-슈미트 직교화 사용)
// dot(input.tangentWorld, N)     : T가 N 방향으로 얼마나 기울어져 있는지 나타내는 스칼라 성분
// dot(input.tangentWorld, N) * N : T를 N 방향으로 투영한 벡터
float3 T = normalize(input.tangentWorld - dot(input.tangentWorld, N) * N);
float3 B = cross(N, T);

float3x3 TBN = float3x3(T, B, N);
normalWorld = normalize(mul(normalTex, TBN));
```

#### 그람-슈미트 직교화
![그람-슈미트 직교화](/assets/img/sherlock/tangent/tangent-07.png)

- 정점에서 계산한 Tangent가 Normal과 정확히 수직이 아닐 수 있어서 **보정**하는 원리.
- 이 계산도 Tangent가 이미 올바르게 계산되어 있다는 전제에서만 유효함.

### 4. Tangent 생성 과정

#### 모델 공간의 두 변
- 삼각형의 정점 위치로 두 변 E1, E2를 계산.

![모델 공간의 두 변](/assets/img/sherlock/tangent/tangent-08.png)

#### UV 변화량
- 같은 두 변에 대응하는 UV의 변화량을 계산.

![UV 변화량](/assets/img/sherlock/tangent/tangent-09.png)

#### 두 공간의 관계
- 모델 공간의 두 변은 UV 변화량과 (Tangent, Bitangent)의 선형 결합으로 표현됨.

![두 공간의 관계](/assets/img/sherlock/tangent/tangent-10.png)

#### Tangent / Bitangent 계산
- 이 관계를 풀면 Tangent와 Bitangent를 구할 수 있음.

![Tangent, Bitangent 계산](/assets/img/sherlock/tangent/tangent-11.png)

```cpp
VECTOR3 E1 = v1.pos - v0.pos;
VECTOR3 E2 = v2.pos - v0.pos;

float du1 = v1.uv.x - v0.uv.x;
float dv1 = v1.uv.y - v0.uv.y;

float du2 = v2.uv.x - v0.uv.x;
float dv2 = v2.uv.y - v0.uv.y;

float det = du1 * dv2 - du2 * dv1;

if (fabsf(det) < 1e-8f)
    continue;

float invDet = 1.0f / det;

VECTOR3 T = (E1 * dv2 - E2 * dv1) * invDet;
VECTOR3 B = (E2 * du1 - E1 * du2) * invDet;
```

- `det`가 0에 가까우면 UV가 퇴화한 삼각형이라 건너뜀.

### 5. 결론
- 노말 맵의 노멀은 **텍스처 공간 기준**이라, TBN 행렬로 모델(월드) 공간으로 보내야 함.
- 일반 모델의 TBN은 삼각형의 **위치 변화량과 UV 변화량**에서 계산함.
- 계산한 Tangent는 그람-슈미트로 Normal과 직교하게 보정하고, Bitangent는 `cross(N, T)`로 구함.
- Tangent 벡터는 InputLayout에 포함해서 셰이더에서 받을 수 있음.
